## The Live page reads through your browser login

TikTok's developer portal won't accept the local redirect address a desktop app needs, so the
official API connection from 1.5.0 couldn't be set up. It's gone, and the Live page now works with
nothing to set up:

- **Log in once and it starts.** Every 5 minutes (2, 5, 10, 15 or 30 min in **Settings → Live**) the
  app reads each watched account's TikTok profile in that account's own browser login, with the window
  hidden. Everything from 1.5.0 is kept: today's views, likes, comments, shares and followers, the
  activity feed, milestones, videos taking off, and clips you post from your phone being marked as
  posted by themselves.
- **One browser job at a time.** A reading waits for a post, login or Test posting on the same account
  to finish, and the Live page says "Waiting for the browser". A post that comes due during a reading
  waits only the few seconds it takes.
- **Every 2 hours the reading goes further back** (up to 120 videos); the others read the newest 30,
  which is quicker.
- **If TikTok asks for a captcha**, the page says so. Turn on **Settings → Live → Show the browser while
  reading** and solve it once in the window that opens.
- If the account's TikTok login runs out, the app says so and the Account page offers **Log in** again.
  The Live page keeps reading the public profile meanwhile (or stops, if it doesn't know the @username
  yet). If TikTok shows a different account's profile, the Live page stops and says why.
- **Readings take turns.** With several accounts watched, one reading is queued at a time, so a post
  never waits behind a row of them.

## Removed

- **Connect API**, the **Settings → TikTok API** tab and the developer-app guide.
- **Post with** in Manage accounts: every account posts through TikTok Studio in its browser, as
  before 1.5.0. Accounts that were set to post with the API post through the browser now, once logged in.
- Saved API keys and tokens are no longer read. A removed account's old tokens file is still cleaned up.
- If your Live reading interval was 1 minute or less, it's now 5 minutes (a browser reading takes a few
  seconds, so once a minute would keep the browser open almost all the time).

## Good to know

- TikTok's profile page lists public videos only, so "Only me" posts don't show up on the Live page.
- The account's own login is used, so readings look like you checking your profile.
