## Clips from ClipMonster: always clear where they went

- The **Ready** page now says which folder it watches, where new clips go, and what happened to
  them: "TTVIDEOS: 5 clips brought in, 13 set aside by ClipMonster's quality check · checked 2 min
  ago". Before, nothing showed up and there was no reason given.
- When **New clips** is set to "Leave them in the Library", the Ready page says so and has a
  **Send them here from now on** link. A **Queue N new clips here** button brings in the clips that
  are already in the Library, best first.
- When ClipMonster saves its Automation clips to a folder TikTok Manager isn't watching (for
  example after you change ClipMonster's "Clips go to"), the Ready page points it out with a
  **Watch it** link. The first start after installing offers this too.
- A watched folder that has gone missing is reported instead of skipped without a word.
- Messages in the Activity log are now also written to the log file, so imports can be looked up
  later (Settings → Updates → Open log folder).
