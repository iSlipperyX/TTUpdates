## Profiles for every account

- **Profile…** on the Account page (and in Manage accounts) sets each account's profile picture, name
  and bio. Pick any picture: it's cropped to a square and sized for TikTok.
- **Save and apply to TikTok** fills in TikTok's own Edit profile box in that account's browser, saves
  it, then checks the profile page to make sure TikTok took it.
- TikTok only lets a name change once every 7 days. When it's too soon, the picture and bio are still
  saved, and the app tells you when the name can change.
- **✨ Suggest bios** writes three bios from the account's niche and recent captions (needs the
  Anthropic API key in Settings → AI).
- Accounts with a picture show it instead of the coloured letter, everywhere accounts are listed.

## Installs like a normal app

- New: **TikTokManager-Setup.exe**. It installs for your Windows user (no admin prompt), adds Start menu
  and desktop shortcuts, and shows up in Windows' list of installed apps. Uninstalling asks whether to
  keep your data.
- Optional for you: your current TikTokManager folder keeps working and keeps updating. To switch, run
  the installer, then delete the old folder. Your accounts, queue and logins are shared, so nothing is lost.

## Updates you can trust

- Settings → Updates shows when it last checked and what it found ("Up to date", a new version, or the
  problem in plain words).
- **What's new** lists every version since yours, not only the latest one.
- New versions are now built and published by GitHub, so releasing no longer needs a token or a long
  build on the PC.
