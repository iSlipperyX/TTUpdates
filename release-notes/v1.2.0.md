## Logging in works again

- **Log in** now opens a normal Edge (or Chrome) window instead of the app-controlled one, which
  TikTok was refusing with "Too many attempts". Log in there, close the window, and the app picks the
  login up. The QR code works too.

## Your data is safe

- Every save keeps the previous file and a daily copy for a week. If your library, settings or
  account list is ever damaged, TikTok Manager loads the newest good copy, keeps the damaged file,
  and tells you. Before, a damaged library opened empty and the next save wiped the real one.
- If the app closes in the middle of an upload, that video is no longer queued again (autopilot could
  have posted it twice). It's marked failed with a note to check TikTok, and the next stats refresh
  marks it posted by itself if it went up.

## Posting test

- **Test posting** on the Account page walks TikTok Studio's upload page with a 3-second black test
  clip, up to just before Post, then throws the clip away. Nothing is posted.
- With autopilot on, a quicker check runs about once a day and warns you if TikTok has changed its
  upload page or logged the account out, before a scheduled post fails.

## When something goes wrong

- Unexpected errors now show a message instead of failing silently, and their details are saved.
- **Settings → Updates → Copy diagnostics** copies everything needed for a bug report (no keys or
  logins). **Open log folder** is next to it.
- The log file no longer grows forever.
