## Logging in connects by itself

- After you log in, TikTok Manager now notices straight away, closes the login window and connects
  the account. Before, it waited for you to close the window and only said so in the Activity line,
  so it looked like nothing happened.
- A **Log in to TikTok** box shows what to do while the window is open, with **I'm logged in** (if
  the window stays open) and **Cancel**. If the login doesn't go through, you now get a message
  saying why.

## Updates install again

- Clicking **Restart to update** closed the app but never installed anything: Windows PowerShell
  quietly refused to run the installer the way the app started it. Fixed, so updates from 1.2.1 on
  install and restart by themselves.
- Because the fix is in the part that runs the update, **install 1.2.1 by hand this once**: quit
  TikTok Manager (tray icon → Quit) and unzip `TikTokManager-windows.zip` over your TikTokManager
  folder. Your library, queue, settings and logins are kept.
